Language reference

Forms define lambda if quote begin let and or

Numbers + - * / = < > <= >= modulo abs

Lists list car cdr cons append length map filter apply

Predicates & output not null? number? list? display newline

Numbers are 64-bit floats. Strings support \n \t \" \\. Comments begin with ;. Functions use lexical scope. let bindings are evaluated in the enclosing scope. if requires both branches.

Loop is under development. Macros, mutation, dotted pairs, and tail-call optimization are not implemented yet. Programs are currently bounded to 100,000 evaluation steps and 128 nested calls; reset the session to reclaim stored definitions. Each top-level expression returns a value; output procedures return ().
